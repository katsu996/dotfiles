# 最終検査

完成前に全項目を確認する。不合格項目がある場合は、部分的な装飾修正だけで済ませず、必要に応じて構造・レイアウト・領域配分から修正する。

## 論理

- [ ] タイトルで主題が分かるか
- [ ] リード文で結論が分かるか
- [ ] ボディがリード文を立証しているか
- [ ] 入力にない因果・順序・優先順位を作っていないか
- [ ] 主図と説明領域が一つのストーリーになっているか
- [ ] 例外・条件・対象外が必要に応じて残っているか

## 構造

- [ ] 最適な図解候補を比較したか
- [ ] 実質的に異なるレイアウトを3案比較したか
- [ ] 単なる表やカードの羅列になっていないか
- [ ] 関係する領域が番号・線・軸・順序などで接続されているか
- [ ] 主図だけで「なぜ」「だから何」が欠けていないか

## デザイン

- [ ] Noto Sans JP で統一されているか
- [ ] タイトル・リード・見出し・本文の強弱があるか
- [ ] 不要な角丸・枠線・影・グラデーションがないか
- [ ] 青系統と限定的な赤だけで構成されているか
- [ ] 情報が一部へ偏らず、空白と密度のバランスが取れているか
- [ ] 不自然な改行・文字切れ・重なりがないか

## PowerPoint

- [ ] すべての主要要素が編集可能か
- [ ] 図形の上に別テキストボックスを重ねていないか
- [ ] 文字が図形内へ直接入っているか
- [ ] 接続線が文字や図形と衝突していないか
- [ ] ヘッダーとフッターの位置が統一されているか
- [ ] `validate.py` が通っているか
- [ ] 画像化して全スライドを目視したか
